## 1: 四隅の丸角

`dazn-wide-player` と、映像から親方向へ検出した `dazn-wide-player-candidate` へ `border-radius: 0 !important` を指定する。適用範囲をフルスクリーン用クラスの配下に限定しているため、通常のプレイヤー表示には影響しない。

確認は、拡張機能を再読み込み後にDAZNプレイヤーをフルスクリーンにし、四隅に残る黒い丸角が消え、通常表示時の角丸が維持されることを手動で行う。
