## 1: フルスクリーン時の余白

`fullscreenchange` 後に `window.innerWidth` を幅計算の上限に使用し、`player-layout` と映像コンテナにも同一の計算済み幅を強制する。フルスクリーン時だけ `TOP_PLAYER_GAP` を 0px にする。

確認は、16:9 の画面で DAZN プレイヤーをフルスクリーン化し、右端・下端に拡張機能由来の余白が残らないこと、通常表示でヘッダー表示とサイドバー非表示が維持されることを手動で行う。
