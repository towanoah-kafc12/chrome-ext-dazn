# フルスクリーン時のビューポート追従方針

## 2026-09-23: プレイヤー寸法はビューポートを基準にする

- 項番: 1
- 内容: `fullscreenchange` を監視し、ネイティブのフルスクリーン状態だけはプレイヤー幅を `window.innerWidth` と映像アスペクト比・表示可能高さから決定する。通常表示の上・左右余白は後続のエッジツーエッジ方針で 0px にする。
- 判断理由: DAZN がフルスクリーンへ遷移した直後にも親要素の通常ページ幅が残る場合があり、その値で算出すると右端・下端に余白が残る。通常表示では `100vw` を強制せず、親レイアウトの外幅を利用して余白だけを除去する。
- 対応ファイル: `app/content.js`、`app/content.css`
- 影響範囲: 通常の映像表示は変えない。映像のアスペクト比と画面比が異なる場合のレターボックス／ピラーボックスは、映像を歪ませないため残る。
