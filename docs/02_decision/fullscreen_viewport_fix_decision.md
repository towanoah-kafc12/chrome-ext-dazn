# フルスクリーン時のビューポート追従方針

## 2026-09-23: プレイヤー寸法はビューポートを基準にする

- 項番: 1
- 内容: `fullscreenchange` を監視し、ネイティブのフルスクリーン状態だけはプレイヤー幅を `window.innerWidth` と映像アスペクト比・表示可能高さから決定し、上端の余白を 0px とする。通常表示は既存の親レイアウト幅と 12px の上端余白を維持する。
- 判断理由: DAZN がフルスクリーンへ遷移した直後にも親要素の通常ページ幅が残る場合があり、その値で算出すると右端・下端に余白が残る。一方で、通常表示で `100vw` を強制することは既存のDAZNレイアウト方針に反するため、ビューポート基準はフルスクリーン時に限定する。
- 対応ファイル: `app/content.js`、`app/content.css`
- 影響範囲: 通常の映像表示は変えない。映像のアスペクト比と画面比が異なる場合のレターボックス／ピラーボックスは、映像を歪ませないため残る。
