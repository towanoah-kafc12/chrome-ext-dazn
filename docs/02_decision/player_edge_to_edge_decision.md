# 通常表示のプレイヤー余白除去方針

## 2026-09-23: 親レイアウトの外幅まで映像を広げる

- 項番: 1
- 内容: 通常表示の上余白を 0px にし、プレイヤー幅の計算には親要素の `getBoundingClientRect().width` を使う。プレイヤーレイアウト自身の左右パディングも 0 にする。
- 判断理由: スクリーンショットで映像の上・左右に約12pxの黒い余白が残った。親レイアウトの内側幅だけを使うとパディング分が映像外側に残るため、外幅を使う必要がある。`100vw` 固定は使わないため、DAZNのページ全体レイアウトやサイドバーとの共存を維持できる。
- 対応ファイル: `app/content.js`、`app/content.css`
- 影響範囲: 通常表示・フルスクリーン表示とも、プレイヤーが利用可能な親領域の端まで広がる。映像比率と表示領域の比率が異なる場合の最小限の余白は維持する。
