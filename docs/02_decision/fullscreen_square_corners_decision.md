# フルスクリーン時の角丸除去方針

## 2026-09-23: 角丸はフルスクリーン時だけ無効化する

- 項番: 1
- 内容: `dazn-wide-player-fullscreen` が付く間だけ、映像本体と映像コンテナ候補の `border-radius` を `0` に強制する。
- 判断理由: フルスクリーンの四隅にだけ残る黒い丸角は、映像比率による余白ではなくプレイヤーDOMの角丸による表示と判断した。通常表示でのDAZNの角丸デザインは維持する。
- 対応ファイル: `app/content.css`
- 影響範囲: ネイティブのフルスクリーン中だけ映像領域の四隅が直角になる。通常表示、ヘッダー、サイドバーのスタイルは変更しない。
