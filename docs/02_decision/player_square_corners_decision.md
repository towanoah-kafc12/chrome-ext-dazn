# プレイヤー角丸除去方針

## 2026-09-23: 通常表示でもプレイヤーの角丸を無効化する

- 項番: 1
- 内容: 映像本体と、映像から親方向へ検出したプレイヤーコンテナ候補に対する `border-radius: 0 !important` を、フルスクリーン状態ではなくプレイヤー表示中に常時適用する。
- 判断理由: 通常表示のスクリーンショットでも映像領域の四隅に丸角が残っている。対象をコンテンツスクリプトが検出したプレイヤー階層に限定すれば、ページ全体のカードやヘッダーには影響しない。
- 対応ファイル: `app/content.css`
- 影響範囲: DAZNプレイヤーの通常表示・フルスクリーン表示の四隅は直角になる。プレイヤー以外のDAZN UIは変更しない。
